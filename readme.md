### BeamSim

This repository is a small project showing the interferences obtained when emitting a sinusoidal signal from an array of emitter.

The current project allows for a linear phase shift \Phi between the emitters, \Phi can be editted while the simulation is running with the slider in the top left. The update only occurs after you've relased the slider.

The next objective is to optimise the computation of the beam as it currently takes around 700ms for a 500 by 500 image.
